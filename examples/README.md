# 履约建模案例

| 案例                                                | 业务问题                                           | 如何追溯                                                                                               |
| --------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [数字广告](digital-advertising/README.md)           | 投放订单一定要先报价吗？                           | 直接签署的订单没有报价；经磋商签署的订单可以反查中选报价。两条路径签署的都是独立订单。                 |
| [产研迭代](agile-sprint/README.md)                  | 锁定待办清单就算交付了吗？                         | 一次基线锁定只确定范围。产品负责人在同一迭代窗口内逐条验收故事，每条验收都指向这份基线。               |
| [共享结算](shared-settlement/README.md)             | 同一笔收入如何同时计入季度和年度，而不重复入账？   | 两个指标请求共用一份收入凭证。季度锁账是另一项确认，指向季度请求和已登记的收入，不改变年度记录。       |
| [跨境设备采购](full-spectrum-procurement/README.md) | 卖方如何证明交付，银行凭什么放款或冻结？           | 买卖双方按采购合同交付；买方另与银行签署托管协议。交付确认、检验证书备案和冻结确认分别证明不同的事实。 |
| [B2B 担保采购](b2b-escrow/README.md)                | 三个参与方怎样分别承担订货、锁款、交付和分账责任？ | 四份双边合同界定各自的权责；后续合同使用已形成的订单、锁款或验收确认，不依赖某个订单的「最新状态」。   |
